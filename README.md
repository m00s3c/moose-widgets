# Moose Widgets

A small, lightweight Elementor add-on with two widgets: a **Fullscreen (off-canvas) Menu** and an **AJAX Search** bar.

## Why this exists

I couldn't find a customizable WordPress search bar that delivered the design I wanted, and the same went for an off-canvas menu. Hacking something together from stock Elementor widgets, or installing extra plugins that bundle a lot of features I didn't need, was worse than just building these two properly. So this plugin does these two things and nothing else.

## Widgets

### Fullscreen Menu
An off-canvas, full-screen navigation overlay with a dependency-free SVG toggle. It has styling controls for the trigger (normal and hover states), the overlay and the menu items, and is responsive.

### AJAX Search
A live-results search bar that submits to native WordPress search. It has dropdown, inline and full-width expanding modes, an optional submit button, and responsive controls for the trigger, form, panel and results.

## Requirements

- WordPress 6.2+
- PHP 8.0+
- Elementor (tested up to 3.25)

## Installation

1. Download this repository as a ZIP, or clone it into `wp-content/plugins/moose-widgets`.
2. Activate **Moose Widgets** in WordPress.
3. In Elementor, find the widgets under the **Moose Widgets** category.
